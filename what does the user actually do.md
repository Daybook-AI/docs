## 6. USER FLOW — What does the user actually do?

The user's experience should be **simple and low-effort**. They should not feel like they are filling out a complicated form or maintaining a database.

### 1. Create an account

- User signs up or logs in.
- Their personal journal and insights are kept private to their account.

### 2. Capture a thought or experience

The user opens the application and can:

- Write a short note.
- Write a longer journal entry.
- Optionally record their current mood.
- Optionally add a category or topic.

**Example:**

> “I spent most of today working on my project. I was productive in the morning, but after lunch I kept getting distracted.”

The user does **not** need to manually identify emotions, problems, or patterns.

### 3. Save the entry

- The original entry is stored.
- The system automatically analyzes it in the background.
- AI can identify things such as:
  - Emotions
  - Topics
  - Activities
  - Problems
  - Goals
  - Important events
  - Ideas

### 4. Continue using the application

The user repeats this whenever they have something worth recording.

**Important:**  
The user should **not be required to journal every single day**.

They can record something whenever they:

- Have an important thought.
- Experience something significant.
- Want to remember something.
- Want to reflect on a problem.
- Have an idea.
- Want to understand how they are feeling.

### 5. Ask questions about their history

After enough information has been collected, the user can interact with their personal history through an AI chat.

For example:

> **User:** “Why have I been struggling with productivity lately?”

The system searches and analyzes relevant journal entries.

> **AI:** “Over the last three weeks, you repeatedly mentioned losing focus after working for several hours and taking on too many tasks simultaneously.”

### 6. Discover patterns and insights

The system can surface patterns such as:

- Recurring problems
- Common emotions
- Productivity patterns
- Repeated goals
- Frequent distractions
- Changes in behavior
- Progress over time

The user can then reflect on these insights.

### 7. Take action

The ultimate purpose is not simply to show analytics.

The user uses the insight to make a decision or change something.

**Example:**

```text
Journal
   ↓
AI identifies repeated distraction
   ↓
User discovers the pattern
   ↓
User understands the possible cause
   ↓
User changes their approach
   ↓
User records future experiences
   ↓
System evaluates the pattern again
```

### Core User Flow

```text
CAPTURE
   ↓
User writes or speaks naturally
   ↓
STORE
   ↓
AI organizes the information
   ↓
BUILD MEMORY
   ↓
User continues recording experiences
   ↓
ASK
   ↓
User asks questions about themselves
   ↓
ANALYZE
   ↓
System finds patterns and insights
   ↓
REFLECT
   ↓
User understands themselves better
   ↓
IMPROVE
   ↓
User makes better decisions or changes behavior
```

### The most important principle

> **The user should spend their effort expressing themselves, not organizing their data.**

The application should handle the difficult work of **organizing, remembering, searching, and analyzing** their experiences.

So the user's job is essentially:

**“Tell the system what is happening in your life. Let the system help you understand what it means over time.”**
